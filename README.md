# 원의 둘레와 넓이 탐구실

초등학교 6학년 2학기 수학 5단원 「원의 둘레와 넓이」 수업용 인터랙티브 웹앱입니다. 1~10차시 흐름에 맞춰 학생이 직접 조작하며 탐구합니다.

| 차시 | 활동 |
|---|---|
| 1 | 원의 중심·반지름·지름·원주 살펴보기, 준비 운동 |
| 2 | 정육각형·정사각형으로 원주 어림, 원을 굴려 원주 펼치기 |
| 3 | 줄자 위에서 물건 굴려 원주 재기 → 원주율 발견 |
| 4 | 굴렁쇠 굴리기, 원주·지름 구하기 연습 |
| 5 | 정사각형과 모눈으로 원의 넓이 어림 |
| 6 | 원을 잘라 펼쳐 직사각형 만들기 → 넓이 공식 |
| 7 | 꽃밭·정사각형 속 원·트랙의 둘레와 넓이 |
| 8 | 수학 놀이 「내 행성을 찾아라!」 (2~4명) |
| 9 | 원 모양 vs 정사각형 시루떡, 1 cm²당 가격 비교 |
| 10 | 단원 정리 퀴즈 (매번 새 문제) |

`index.html` 한 파일로 동작하며, `main`에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다. 특정 차시로 바로 가려면 주소 뒤에 `#l3`처럼 붙이면 됩니다.
